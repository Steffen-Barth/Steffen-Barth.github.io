# Bewerberprofil – Steffen Barth

Statische Single-Page-Webseite als Bewerberprofil. Optimiert für GitHub Pages.

## Features

- **Dark & Light Mode** mit Umschalter (folgt der System-Einstellung, Auswahl wird im Browser gespeichert)
- **Tech-Look** mit Monospace-Akzenten
- **Sprachumschalter** Deutsch / Englisch (Auswahl wird im Browser gespeichert)
- **Live-Projekte** als statische Karten (4 eigene Webseiten/Services) mit Link zum GitHub-Profil
- **Responsive** für Desktop, Tablet und Mobile – inkl. Hamburger-Menü
- **Social-Sharing** vorbereitet via Open-Graph-Tags + SVG-Favicon
- **Kein Build-Schritt** – reines HTML/CSS/JS

## Lizenz

Persönliches Bewerberprofil – nicht zur Weiterverwendung.
